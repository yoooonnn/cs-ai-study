# 주간 논문 리뷰

일주일에 논문 한 편을 읽고 리뷰를 남긴다.

## 규칙

- 파일 하나에 논문 하나: `papers/YYYY-짧은이름.md` (YYYY는 논문 발표 연도, 예: `2017-transformer.md`)
- 새 리뷰는 [`TEMPLATE.md`](TEMPLATE.md)를 복사해서 시작한다.
- 다 쓰면 아래 목록에 한 줄 추가한다. velog에 올렸다면 링크도 적는다.
- 원본은 이 저장소이고, velog는 선택이다. 마크다운을 그대로 붙여넣으면 된다.
